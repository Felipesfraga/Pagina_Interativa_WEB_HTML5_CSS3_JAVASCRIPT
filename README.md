# 🖥️ Componentes do Computador — Guia Interativo de Hardware

Uma aplicação web interativa e educativa desenvolvida para apresentar as principais partes e o funcionamento do hardware de um computador, além de demonstrar conceitos fundamentais de manipulação do DOM através do JavaScript.

## ✨ Funcionalidades

- 🧩 **Explorador Interativo de Hardware:** Exibe descrições detalhadas e didáticas sobre a CPU, Memória RAM, Placa de Vídeo (GPU) e Armazenamento (HD/SSD) ao clicar nos botões correspondentes.
- 🎨 **Controle de Estilo Dinâmico:** Botão para alterar a cor de fundo (*background*) do site em tempo real via JavaScript.
- 🔤 **Ajuste de Fonte:** Opções para aumentar e diminuir o tamanho do texto explicativo dinamicamente.
- 👁️ **Visibilidade de Elementos:** Funções para esconder e mostrar novamente o bloco de descrição no DOM.
- ✏️ **Manipulação de Título:** Botões para alterar o título principal da página e restaurá-lo ao estado original.

## 🚀 Como Executar o Projeto

1. **Clone ou baixe** este repositório para o seu computador.
2. Abra o arquivo `index.html` em qualquer navegador web moderno (Google Chrome, Firefox, Edge, etc.).

---

## 💡 Aprendizados e Práticas Aplicadas

- Manipulação do DOM (Document Object Model) utilizando `document.getElementById()`.
- Alteração dinâmica de conteúdos HTML via propriedade `.innerHTML`.
- Modificação de propriedades de estilo inline via JS (`element.style.fontSize`, `display`, `backgroundColor`).
- Associação de eventos de clique (`onclick`) diretamente nos elementos de botão.
- Estilização com CSS3 utilizando Flexbox, bordas arredondadas e efeitos de `hover`.
